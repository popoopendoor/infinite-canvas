# 快速开始

OAuth 登录和 `money` 计费需要完整 Docker 服务：Nginx 提供 `web/` 前端，并把同源请求转发给 Node.js BFF。

## Vercel 部署

Vercel 仍可以构建静态 `web/` 前端，但不会运行 BFF，因此不满足这里的 OAuth 和计费部署要求。完整服务请使用 Docker。

## 本地启动

```bash
git clone git@github.com:popoopendoor/infinite-canvas.git
cd infinite-canvas
cd web
bun install
bun run dev
```

启动后访问：

```text
http://localhost:3000
```

## Docker 启动

如果你需要基于当前源码构建完整服务：

```bash
cp .env.example .env
# 编辑 .env，填写所需的集成配置。
docker compose -f docker-compose.local.yml up -d --build
```

## 首次使用建议

- 在 Flarum OAuth 中登记精确的 `/auth/callback` 地址，并单独安装、配置 Canvas Money Bridge。
- 管理员在 BFF 的 `MODEL_CATALOG_JSON` 发布模型和固定价格，并在 `MODEL_PROVIDER_KEYS_JSON` 配置托管模型的 provider key。登录成功后，模型会自动出现在 `Canvas 托管` 配置中，不需要用户再填写 provider key；请求会先从当前 Flarum `money` 余额预扣，成功后扣除，明确失败则释放。
- BYOK 仍可使用：把模型发布到 `MODEL_CATALOG_JSON` 但不映射服务端 key，再在配置中填写自己的 `Base URL` 和 `API Key`。浏览器只会在单次请求前加密 key 交给 BFF，BYOK 请求同样经过余额计费。
- 如果需要提示词仓库内容，打开 `/prompts` 会由浏览器前端直连拉取并缓存到 IndexedDB。
- 如果需要跨设备同步画布、素材和生成记录，可在配置弹窗中填写 WebDAV。

## 说明

- 当前画布项目和“我的素材”主要保存在浏览器本地，WebDAV 同步需要用户自行配置。
- BFF 负责 OAuth、已发布模型和计费；浏览器不会拿到 OAuth token 或 bridge token。
