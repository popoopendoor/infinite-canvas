# Docker Deployment

## Run the full stack

```bash
git clone git@github.com:popoopendoor/infinite-canvas.git
cd infinite-canvas
cp .env.example .env
# Edit .env with the Flarum OAuth, bridge, model catalog, and provider allowlist values.
docker compose up -d --build
```

Open `http://localhost:3000`.

The production Compose file starts the Nginx frontend and the independent Node.js BFF. The Flarum Money Bridge is installed separately in the Flarum site; it is not included in the Canvas image. `OAUTH_REDIRECT_URI` must exactly match the callback registered in Flarum.

## Build locally

```bash
docker compose -f docker-compose.local.yml up -d --build
```

The local file allows empty integration settings for UI and health-check work. OAuth and billed model requests require the corresponding values in `.env`.

## Documentation image

The documentation in `docs/` is a separate Next.js standalone application with server capabilities.

```bash
cd docs
docker compose up -d
```

To build it from the current source:

```bash
cd docs
docker compose -f docker-compose.local.yml up -d --build
```

Canvas projects, My Assets, generation history, and local provider configuration remain in the browser by default. The BFF stores sessions, task states, and reconciliation data in the `canvas-bff-data` volume. Do not expose that volume or the OAuth, bridge, and provider credentials.

## Optional analytics

No analytics are enabled by default. A deployment can enable GA4, Baidu Analytics, or both at runtime:

| Variable | Description |
| --- | --- |
| `ANALYTICS_GA4_ID` | Google Analytics 4 measurement ID (`G-XXXX`) |
| `ANALYTICS_BAIDU_ID` | Baidu site ID, the hash after `hm.js?` |

```yaml
services:
  app:
    image: infinite-canvas:latest
    ports:
      - "3000:3000"
    environment:
      ANALYTICS_GA4_ID: G-XXXXXXXXXX
      ANALYTICS_BAIDU_ID: e8263761cc5c32f5f7a855b8203b965a
```

SPA route changes automatically report page views to enabled providers. Only configure analytics IDs on sites you control, and do not commit them to the repository.
