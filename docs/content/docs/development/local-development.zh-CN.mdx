# 本地开发

主应用由 `web/` 前端和 `server/` Canvas BFF 组成。纳入 OAuth 与 `money` 计费的模型请求经 BFF 处理；本地 Agent 仍在用户电脑上运行。

## 1. 启动前端

```bash
cd web
bun install
bun run dev
```

前端默认访问：

```text
http://localhost:3000
```

## 2. 启动 BFF

另开终端执行：

```bash
cd server
npm ci
npm run dev
```

Vite 会把 `/auth`、`/api` 和 `/health` 代理到 `http://localhost:3001`。

## 3. 配置模型

在 BFF 启动环境中设置 `MODEL_CATALOG_JSON` 和 `MODEL_PROVIDER_KEYS_JSON`。登录后，映射了服务端 key 的模型会自动进入 `Canvas 托管` 配置，并按目录中的固定价格使用 Flarum `money` 余额。托管模型的接口、协议和模型清单由服务端锁定。

BYOK 仍可保留：把模型发布到目录但不设置对应的服务端 key，再在配置弹窗填写 `Base URL` 和 `API Key`。BYOK key 保存在浏览器，并在请求前加密交给 BFF；所有通过 Canvas 发起的模型请求仍走同一计费链路。

## 4. 启动文档站

如果需要单独调整文档站，在 `docs` 目录执行：

```bash
bun run dev
```

## 常见场景

- 改画布、页面和交互：主要看 `web/`
- 改提示词缓存：主要看 `web/src/services/api/prompts.ts`
- 改文档站内容：主要看 `docs/content/docs/`
